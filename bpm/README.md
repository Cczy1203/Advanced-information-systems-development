# BPMN process baseline

This folder is used for the initial BPMN configuration and workflow artefacts for the Hospital Patient Administration System.

## Current status
- Initial process skeleton created.
- The model is deliberately a baseline for discussion and further refinement.
- The final submission should evolve this skeleton into a more complete executable model with process variables, gateways and service interactions.

## Planned process areas
- Referral intake and document validation
- Consultant decision and appointment booking
- Treatment planning and funding checks
- Payment handling and exception management
- Clinical review and treatment modification
- Follow-up scheduling and outpatient communication
- Clinic letter approval and escalation
- Enquiry triage and audit reporting

## Development note
The BPMN file should be updated each sprint with evidence of:
- process improvements
- exception handling changes
- configuration management changes
- validation of flow paths against requirements
